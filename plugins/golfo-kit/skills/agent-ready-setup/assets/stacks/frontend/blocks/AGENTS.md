## Frontend

The Frontend stack of agent-ready-setup covers web frontends. Its rules are listed above (`.agents/rules/frontend-security.md`, `.agents/rules/frontend-testing.md`, `.agents/rules/server-first-data-flow.md`, among others).

To review a pull request, run `/frontend-review-pr`: it runs the `frontend-security-scanner`, `a11y-reviewer`, `frontend-perf-analyzer`, `test-reviewer` and `lint-reviewer` agents.

Skills of this stack: `component-creation`, `api-endpoint`, `service`, `logger`, `react-act-test-fixes`, `karpathy-guidelines`.
