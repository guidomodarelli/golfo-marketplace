# Formato de los reportes contables

- Los importes van con dos decimales, coma decimal y punto de miles (`$ 1.234,56`), alineados a la derecha en las tablas.
- Las fechas van en formato `AAAA-MM-DD`.
- Cada reporte termina con la sección `## Pendientes`: lo que falta confirmar, con quién y para cuándo; si no falta nada, dice «Sin pendientes».
- Una cifra que no se pudo verificar contra un comprobante queda marcada `[a verificar]`, nunca estimada.
